# safari-plus

Emerald Safari overhaul. Every wild encounter is turned to play with emerald's safari minigame.

This means that safari exploration is free of entrance fee (step counter for exit and the max 30 safari balls cap are removed), this is to ensure the safari mode isn't broken nor sends player to safari area wrongly after balls reach 0 quantity.

I managed to beat the game without issues in the prior versions of g1r release, but keep in mind that future updates might break the safari mod as it essentially redirects combat into native safari, if something is to change at any point by g1r updates, this breaking is always a possibility.

What do upgrades do:
-Safari Upgrade, increases safari ball catch rate up to +21% catch rate.
-Safari Ball capacity, increases max balls held by player.
-Ball Recovery, speeds up the rate safari balls are generated for player.
-Likeability, reduces the chances of pokemon running away from player after each action in safari mode, legendaries have 50% chance of runnning away, maxed skill reduces it to 9% instead.
